# Doctor Report Template

This is a source template for generated doctor diagnostics.

Runtime doctor reports are generated at:

- `reports/doctor.md`
- `AI_CONTEXT/doctor/doctor.json`

These generated files can contain local absolute paths, installed model names,
runtime versions, and machine-specific diagnostics. They are intentionally not
versioned.
