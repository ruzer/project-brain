# project-brain 0.2.2 release notes

Release date: 2026-05-12

## Summary

`project-brain` 0.2.2 is a release hygiene update after the architecture-plan workflow. It aligns published package metadata, CLI version reporting, README instructions, and release documentation.

## Changes

- `project-brain --version` now reads from package metadata instead of a hardcoded CLI string.
- README now documents how to run from source, from compiled `dist`, and via optional `npm link`.
- Release checklist now uses `<version>` placeholders instead of being fixed to `0.2.0`.
- Package metadata and output contract are aligned with `0.2.2`.

```bash
npm run verify:quick
npm run test -- tests/unit/cli-command-parsing.test.ts

```
