# project-brain 0.2.4 release notes

Release date: 2026-05-13

## Summary

`project-brain` 0.2.4 hardens local swarm output handling and adds review-safe maintenance coverage for agent behavior and unused export analysis.

## Changes

- Added malformed/code-only worker response detection in the bounded swarm runtime.
- Added `npm run review:exports` to generate a categorized `ts-prune` review report without deleting exports.
- Added unit coverage for `QAAgent`, `SecurityAgent`, `ObservabilityAgent`, and `OptimizationAgent`.

## Validation

```bash
npm run lint
npm run typecheck
npm run build
npm test
npm run review:exports
```
